Simple Python Games:
This repository contains two beginner-friendly text-based games that demonstrate core programming concepts like user input, conditional logic (if/else), and randomization.

1. Rock, Paper, Scissors
A digital version of the classic hand game against the computer.
How it works:
The user picks Rock, Paper, or Scissors.
The computer makes a random choice using the random module.
The program compares choices and declares a winner based on standard rules (Rock beats Scissors, etc.).
Key Concept: Uses random.randint() to simulate the computer's opponent logic.

2. Treasure Island (Mini-Adventure)
A "Choose Your Own Adventure" style game where your choices determine your survival.
Mission: Find the hidden treasure by navigating through a series of dangerous obstacles.
Gameplay Mechanics:
Decision 1: Choose between moving Left (0) or Right (1).

Decision 2: Decide to Swim (1) or Wait (0).

Decision 3: Pick a colored door: Red, Blue, or Yellow.

Winning Condition: Only the Yellow door leads to the treasure!
Key Concept: Demonstrates nested conditional statements (if/elif/else) to create branching storylines.
